# 🏨 Hotel Promotional Website - Gündüz Hotel

A modern, responsive, and elegant promotional website built to showcase the luxury, amenities, and serene atmosphere of Gündüz Hotel. This project features a clean user interface with interactive elements, custom color palettes, and structured sections to provide an unforgettable digital experience for potential guests.

## 🚀 Features

- **Interactive Navigation:** A sleek navbar with responsive links and smooth hover transitions.
- **Hero Section:** A welcoming introduction area with an elegant design and call-to-action buttons.
- **Amenities & Services:** A beautifully structured feature section highlighting core services (24/7 Front Desk, Restaurant Bar, Transfer Services, and Spa Suites) with modern icons.
- **About / Guest Services:** A side-by-side presentation layer matching a premium display image with a full-width background description container.
- **Photo Gallery:** A clean, multi-column flex grid layout with optimized vertical and horizontal spacing to showcase hotel spaces dynamically.

## 🎨 Design & UI Architecture

The project utilizes a custom, production-ready CSS utility system (`utils.css`) built around CSS variables for global color consistency:
- **Primary Accent:** Custom Blue (`#007bff`) used for core buttons, headers, and highlights.
- **Transitions:** State transitions (e.g., button and link hovers) are managed globally with a `0.2s ease-in-out` opacity and transformation system to ensure fluid animations.
- **Grid Layouts:** Uses modern CSS flexbox alignments tailored to prevent layout breaking or side-spilling on content blocks.

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Custom CSS3 (Flexbox & Grid Layouts)
- **Icons:** Font Awesome v6.4.0 (Scalable Vector Icons)
- **Version Control:** Git & GitHub
